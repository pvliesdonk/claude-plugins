# representing-information

Decide what to show, how much, and in what form when information has to reach a
particular audience. The skill routes by occasion — live talk, executive
briefing, report figure, monitoring dashboard, public explainer, workshop
artefact, poster, your own exploration — and by material, for ontologies and
domain models, processes and causal claims, and qualitative findings.

It covers the judgment, not the drawing. For rendering charts use `dataviz`;
for diagram syntax and layout use `creating-diagrams`.

Alongside the recipes sit cross-cutting tools: task abstraction, encoding
choice, density and reduction, audience literacy, uncertainty, titles and
annotation, re-cutting one analysis for a new audience, the line between honest
emphasis and persuasion, and the decision not to draw at all.

Notes mark whether each rule is experimental, convention or contested — this
field circulates a lot of confident folklore, and a skill that flattened it
would get its user caught out.
