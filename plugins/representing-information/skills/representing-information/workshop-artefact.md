# The Workshop Artefact

The one occasion where an unfinished artefact is the correct artefact. Dwell is long — an hour,
sometimes a day — and collaborative. The author is present but as facilitator rather than narrator,
so the artefact's job is to provoke rather than persuade. Control of the view is the most complete
anywhere: participants can look, write on it, cross things out and move it round the room. And the
next action is not to decide, learn or verify but to **mark it up and argue** — so the picture is a
working surface whose value is not what it shows but what people put on it. This occasion punishes
finish: a completed chart has already decided the categories and what counts, which is exactly the
property that makes it good everywhere else. Capable people arrive with a clean deck and receive
validation instead of information.

The useful frame is the **boundary object** — plastic enough that the engineer, the regulator and
the service lead each read it in their own terms, robust enough that they are all looking at the
same thing. That is analytic theory, not a tested design principle, and it is often stretched too
far; used narrowly it explains why a finished chart is the wrong object here, and no further.

## The recipe

1. **Start from the session's decision, not the data.** What must the room argue about? Choosing a
   picture because it represents the data well is the wrong move on the one occasion where that is
   not the job.
2. **Set fidelity deliberately.** Rough — hand-drawn, obviously provisional — draws *structural*
   critique ("is that even the right axis?"); polished draws *tactical* critique ("can we change the
   blue?"). The mechanism is social: people will not tell a colleague that finished work is
   structurally wrong. Fidelity is a control variable, not an aesthetic default — convention, with a
   plausible mechanism and no evidence behind it.
3. **Plan the gaps.** A blank axis, an unlabelled cluster, a visible question mark — each is an
   instruction, and the cheapest facilitation instrument there is: it works without anyone being
   asked out loud.
4. **Make it physically markable**: big enough for several people to write on at once, pens out.
5. **Make the first mark yourself** if the room hesitates. Editability has to be demonstrated, not
   announced.
6. **Capture the marked-up state** as the output, and re-cut before any of it reaches a report or
   board page — photographing the wall into a deck is a resize in costume (`tool-recutting.md`).

**The test: if the artefact would survive the session unchanged, it was the wrong artefact.**

## Required moves

- [ ] **Session decision named first**, artefact chosen against it.
- [ ] **Fidelity set as a choice**, with the trade-off stated.
- [ ] **Gaps designed**, not accidental — accidental gaps read as sloppiness, not invitation.
- [ ] **Physically reachable by several people**, pens out.
- [ ] **First mark made** to break the surface.
- [ ] **Marked-up version captured**; the pristine original discarded.

## Failure modes

- **Arriving with the finished deck** — participants read instead of working.
- **Polish as unintended foreclosure** — a clean artefact made by habit, then only cosmetic comments.
- **The artefact that survives intact** — clean at the end means nothing happened.
- **Too plastic to be shared** — so loose each participant reads a different object; the frame needs
  robust common structure as well as flexibility.
- **One-person access** — too small, too high, or a screen only the facilitator controls, which
  collapses the session into a live talk without narration.
