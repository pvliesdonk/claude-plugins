# Representation Tools (on-demand techniques)

Cross-cutting techniques the core moves and occasion files invoke. Reach for one when designing and
especially when reviewing — each is self-contained, marks what is experimental, what is convention
and what is contested, and names an optional source corpus note for depth.

| Reach for… | When |
|---|---|
| `tool-task-abstraction.md` | naming what the reader must *do* before any form is chosen — Munzner's what/why/how, the four threats, the four-line pre-brief |
| `tool-encoding-choice.md` | assigning variables to channels: Bertin's levels, expressiveness as a hard filter, accuracy rankings and their limits |
| `tool-contested-rules.md` | a rule is being asserted — pies, 3D, dual axes, rainbow, squarified treemaps, 7±2 — and you need what the evidence actually says |
| `tool-how-much.md` | deciding density: the three reading contracts, data-ink as diagnostic, comparison layouts, overview and disclosure |
| `tool-aggregation.md` | rolling up, binning or de-cluttering — and the reduction is quietly making a statistical claim; plus what cognitive load really governs |
| `tool-audience-literacy.md` | setting the floor for a general audience, or resisting "my audience are experts" as a design argument |
| `tool-uncertainty.md` | showing a range, an interval, a distribution or a risk — and choosing the format honestly |
| `tool-titles-and-annotation.md` | writing the title and the annotation layer: the highest-leverage, least-policed channel in the artefact |
| `tool-recutting.md` | the work exists and the audience changed — what stays invariant, and when to start again from the material |
| `tool-honesty.md` | telling legitimate emphasis from quiet persuasion, and knowing what is demonstrated to mislead |
| `tool-when-not-to-draw.md` | deciding whether a picture is warranted at all, and running a critique in the order that can catch real failures |
