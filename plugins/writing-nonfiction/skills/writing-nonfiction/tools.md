# Writing Tools (on-demand techniques)

Cross-cutting craft techniques the core moves and genre files invoke. Reach for one when drafting or (mostly) revising. Each is self-contained; an optional source corpus may provide fuller notes.

| Reach for… | When |
|---|---|
| `tool-front-loading.md` | the point is buried; a reader decides in the first lines (BLUF / inverted pyramid / SCQA / answer-first) |
| `tool-argument-structure.md` | building a case: Minto pyramid, SCQA opener, MECE grouping, Toulmin (claim/grounds/warrant) |
| `tool-the-gap.md` | justifying *why this matters*: the CARS move (territory → niche/gap → occupy) |
| `tool-narrative-spines.md` | reducing the whole thing to one compelling sentence (ABT) or a moving arc (OCAR) |
| `tool-audience-and-curse-of-knowledge.md` | deciding who you write for, and why experts write unclearly |
| `tool-heilmeier.md` | pressure-testing a proposal or idea with eight jargon-free questions |
| `tool-plain-language.md` | the prose is dense, jargon-heavy, hard to read first time |
| `tool-sentence-clarity.md` | sentences are correct but clunky: cohesion, emphasis, characters/actions, cutting lard |
| `tool-ai-tells.md` | the draft reads as machine-generated; strip the synthetic register |
| `tool-revision.md` | a draft exists; revise it in the right order (big to small) |
| `tool-figures-and-data.md` | a figure, table, or data point must do persuasive or evidential work |
| `tool-signalling-negotiability.md` | a draft must read as provisional / for-discussion / negotiable, not as settled fact |
