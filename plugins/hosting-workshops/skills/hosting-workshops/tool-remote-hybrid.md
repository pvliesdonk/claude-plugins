# Remote & Hybrid Facilitation

Moving a workshop online is a *different craft*, not the same session on a screen. The facilitator's basic instrument — reading the room — largely fails: ambient cues collapse, attention fragments against everyone's desktop. The response is not to sense harder but to **replace ambient feedback with designed structure.**

## Virtual: build structure in
- Shorter blocks; a **mode switch every 15–20 min**; cap remote sessions (~4 h) with frequent breaks.
- Run an **engagement cadence** — rotate polls, chat, reactions/hand-raise, breakout rooms, a shared canvas, named address ("Amara, your read?"). Visible participation, constant.
- **Cameras: encourage, don't mandate** (bandwidth/space/wellbeing); set the norm at the open. **Avoid tool saturation** — prefer tools the group knows.
- **Digital whiteboards** (Miro/Mural) are the sticky-note substrate online — and async contribution *reduces* production blocking (no one waits to post).

## Hybrid: the equity problem (the hardest mode)
Remote participants are *systematically* disadvantaged — in-person dominance, the majority effect, facilitator attention drifting to the room. Level it by pushing the privilege out of the room:
- **Remote-first turn order** — remote responds before the room.
- **A remote-advocate co-facilitator** watching the remote channel.
- **Everyone on their own device** so interaction flows through the tool equally (mind audio collisions — headphones).
- **Design virtual-first**; narrate visual/nonverbal info aloud; don't run mixed-modality breakouts.

## Video-call fatigue (real research)
"Zoom fatigue" has four causes (Bailenson): close-up eye gaze, nonverbal overload, the self-view mirror, reduced mobility. Fixes: **hide self-view**, shrink the grid, allow audio-only stretches, build in movement. A long, back-to-back synchronous day maxes every fatigue dimension — shorten live blocks and move work **async** where you can (better for time zones, scale, depth, inclusion; blend short sync touchpoints with async between).

## The producer role & Plan B
You can't facilitate *and* run the tech — split it: lead owns engagement, a **producer** owns platform/chat/breakouts/timing. "Not *if* but *when*" a tool breaks: a backup channel announced in advance, a backup device, an analog fallback; tech-check before, not during.

## Failure modes
- **In-person workshop ported** — same agenda on Zoom, no added structure; it drifts unseen.
- **Verbal-only hybrid** — remote can't break in; they go silent.
- **Solo online facilitation** — engaging + timing + firefighting tech; all degrade.
- **The all-day video marathon, cameras mandatory** — maxes fatigue.
