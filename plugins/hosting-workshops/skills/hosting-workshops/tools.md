# Facilitation Tools (on-demand techniques)

Cross-cutting facilitation techniques the core moves and session files invoke. Reach for one when designing or running a session. Each is self-contained; an optional source corpus may provide fuller notes.

| Reach for… | When |
|---|---|
| `tool-the-arc.md` | shaping the session: backward design (outcome → evidence → activities), the diverge → groan-zone → converge → close diamond, timeboxing, energy curve, scoping & pre-work |
| `tool-ideation.md` | generating options: why write-first beats open-floor brainstorming (production blocking), 1-2-4-All / brainwriting / NGT, and divergent techniques (SCAMPER, Double Diamond) |
| `tool-convergence.md` | narrowing and deciding: gradients of agreement, dot voting, multivoting, impact-effort, MoSCoW, and the decision rule (consensus / consent / leader-decides) + owned action |
| `tool-facilitation-moves.md` | the in-room verbal craft: ORID (focused conversation), open vs. closed questions, active listening, neutrality, honest pacing |
| `tool-group-dynamics.md` | the room's climate: Tuckman's stages, psychological safety, ground rules, managing dominators / silence / conflict structurally |
| `tool-methods.md` | choosing a concrete activity: the microstructure library (1-2-4-All, affinity, fishbowl, retro shape, icebreakers/energizers) and the large-group formats |
| `tool-remote-hybrid.md` | running it online or mixed-presence: engagement cadence, digital whiteboards, the hybrid equity problem, the producer role, video-call fatigue, async |
| `tool-logistics.md` | the physical/operational layer: room & seating, materials kit, group size, accessibility, contingency / Plan B, co-facilitation |
| `tool-training-science.md` | designing practice that sticks (for training): worked examples, expertise reversal, the testing effect, spacing, scaffolding, formative assessment |
| `tool-evaluation.md` | telling whether it worked and making it stick: Kirkpatrick (and why the chain is weak), the smile-sheet problem, the transfer problem, capturing outputs, the after-action review |
