# The Science of Practice (for Training)

For sessions that *teach a skill*, the learning science is unusually strong — replicated across decades — and unusually ignored. These are the highest-leverage moves in `technical-training.md`.

## Worked examples, and the expertise-reversal trap
- For a **novice**, studying a *fully worked example* beats solving the equivalent problem — open problem-solving consumes the working memory that schema-building needs. Don't hand novices the cold problem.
- This **reverses with expertise**: worked examples bore and slow experts (redundant load); they learn more by solving. So sequence **worked example → completion problem → independent problem**, and **tier** for mixed levels (core task + stretch).

## Deliberate practice
Skill comes from *effortful, targeted* practice on the specific sub-skill, with **immediate, diagnostic feedback**, at the edge of current ability — not from doing-a-lot. An exercise that produces output but no focused feedback on the hard part feels productive and teaches little. (The "10,000 hours" rule is a misreading.)

## Retrieval & spacing (treat as learning, not testing)
- **Testing effect** — *retrieving* from memory ("without looking, what's the command?") strengthens retention far more than re-reading, which only feels like mastery. Build low-stakes recall in; it's a learning event.
- **Spacing** — distributed practice beats cramming. Recap-and-recall at the start of each segment; revisit earlier material across sessions.

## Scaffolding & formative checks
- **Scaffold, then fade** — worked examples, cue sheets, a co-pilot are fine early; *plan their removal* or dependence persists. Sequence whole-but-simple before complex.
- **Formative assessment** — in-flight checks (the retrieval prompts double as these) to see who's lost and adjust live; tier and pair for mixed levels.

## Failure modes
- **Cold open problems for novices** — they drown in cognitive load.
- **Practice without feedback** — busy, but little learned.
- **Re-reading mistaken for learning** — fluency illusion, poor retention.
- **Massed cramming / scaffolds that never fade** — gone in days; dependence persists.
- **One exercise for all levels** — expertise reversal ignored.
